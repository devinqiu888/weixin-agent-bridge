# 数据与安全说明

本项目为实验性、单账号自托管服务。公开源码不等于已经完成生产安全审计。

## 数据流与存储

微信消息正文及回复上下文保存在部署者的 SQLite Durable Object 中；事件会将消息数据交给已授权的 ChatGPT 服务。微信机器人令牌保存在绑定状态中；OAuth access/refresh token 以哈希方式保存。管理员令牌使用 Cloudflare secret。

超过 24 小时的待处理消息在轮询时清理。发送中、已发送及结果不确定的记录保留用于去重；主动断开会删除本应用的本地绑定和消息数据。应用删除不等于 Cloudflare 备份、恢复机制或 ChatGPT 侧数据立即消失。

管理诊断只提供计数、过滤原因和时间等信息，不保存消息正文或用户 ID。不要另行开启会记录完整凭据、回调 URL、请求正文的日志。

## 授权边界

- 每个部署仅允许一个微信所有者、一个有效 OAuth grant 和一个事件订阅。
- 管理令牌具有本部署的管理权限，不应提供给其他用户。
- `wechat_reply` 必须引用已有消息，且收件人必须是绑定所有者。
- 新授权会撤销旧授权和订阅；同步失败期间不应假定所有在途请求已立即消失。
- 断开、撤销或重新部署不能收回已经开始的外部发送。

## 回调限制

只允许部署者配置的精确 HTTPS 回调主机，并禁止重定向。当前实现没有提供完整的 DNS 重绑定防护或连接时 IP pinning，因此不应向任意不可信客户端开放回调地址选择。

## 发送结果不确定

发送前记录预约；上游超时或中断时保留 `uncertain` 状态。不要自动再次发送同一条回复，否则可能产生重复消息。需要结合原会话实际收件情况处理。

## 公开仓库

不要提交 `.dev.vars`、`.env`、`.wrangler/`、真实消息、二维码、OAuth token、机器人 token、私人回调地址或原始云端诊断文件。问题反馈只提供脱敏信息；不要在公开 Issue 中发布凭据。
