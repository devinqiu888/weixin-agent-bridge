# 验证记录

## 2026-10-30：首轮真实文字链路

在一个 Cloudflare 部署、一个微信账号与一个 ChatGPT dot 上完成：

- OAuth 安装、工具发现和 `message.created` 事件发现。
- 本人微信扫码绑定。
- 真实事件订阅及签名 challenge 验证。
- 4 次由消息事件自动触发的处理，4 次 `wechat_reply` 返回发送成功。
- 管理端记录 `sent:4`，待处理、发送中、不确定、待发事件和失败事件均为 0。
- 用户明确确认手机微信原会话已收到回复。

依据 dot 的运行记录，4 次从事件生成到发送成功约为 34、95、37、89 秒。这些是单次测试的估计，不是端到端精密计时或性能保证。

公开仓库不包含个人聊天截图、原始消息 ID、测试账号凭据、私人部署地址或原始云日志。

使用者反馈已实际测试，图片传输能够完成。本项依据使用者实测反馈，本轮未由维护 agent 独立复测。具体传输方向、格式、大小限制和实现路径尚未形成完整测试记录；不据此推定所有文件类型或双向传输均已支持。

## 自动化验证

`npm run check` 执行 TypeScript 检查和模拟上游测试，覆盖微信协议适配、MCP、OAuth、事件签名、存储、去重和路由。`npm run build` 执行 Wrangler dry-run。模拟测试不能替代真实客户端、微信收件或平台审核。
